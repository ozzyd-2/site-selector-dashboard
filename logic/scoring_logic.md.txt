WaterRisk Explorers — Scoring Logic (v2)
========================================

Purpose
-------
The dashboard converts city-level environmental and infrastructure data into
comparable **pillar scores** on a **0–1** scale (higher = worse within the
current city cohort), then combines them into a **Total Impact Score** on a
**0–10** scale. **Lower totals mean better sites.**

Implementation lives in `logic/site_scores.py` (Python) and mirrors the
formulas in `index.html` (JavaScript) for the interactive UI.

Normalization
-------------
For each numeric input column used in a pillar, apply **min–max** normalization
across the scored rows only:

  norm(x) = (x − min) / (max − min)

Constants (all NaN) → NaN pillar inputs; identical values → 0.

**Inverted inputs (dryness):** for annual precipitation, use
`1 − norm(precipitation)` so **less rain = higher risk**.

Location variables (**latitude**, **longitude**) are **not** scored; they are
for mapping only.

Data sources
------------
- **Primary table:** `data/excel_database(Variables).csv` (city rows with
  `Avg_Summer_Temp` present; facility appendix rows are excluded).
- **Optional enrichment:** `data/excel_database(grid_carbon).csv` merged on
  `city` (CO₂ million metric tons, state grid MWh) and on `state_ID`
  (industrial total price rows), when parsing succeeds.

Variables used by pillars
-------------------------
| Theme | CSV column | Role |
|-------|------------|------|
| Water | Water_Stress_Index, Drought_Risk, Water_Price | Scarcity, drought, cost |
| Water | avg_Annual_Precipitation | Inverted → dryness stress |
| Water | Rain_Jan … Rain_Dec | Std dev across months → variability |
| Climate | Avg_Summer_Temp, Cooling_Degree_Days | Cooling load |
| Climate | Avg_Annual_Temp, Heating_Degree_Days | Broader thermal / HVAC exposure |
| Carbon | Grid_Carbon_Intensity | kg CO₂ / MWh |
| Carbon | CO2_million_metric_tons (merged) | State grid CO₂ mass |
| Carbon | Grid_MWh (merged) | State generation scale |
| Energy cost | Electricity_Price (Variables) | Cleaned numeric; often state industrial total proxy in this dataset |
| Energy cost | Industrial_Total_USD (merged) | Secondary cost signal when available |

**Industrial electricity price national average** from the grid workbook is a
single benchmark, not a per-city differentiator, so it is **not** a scored
column. **Carbon per MWh** is represented by **Grid_Carbon_Intensity** (and
averaged with merged CO₂/MWh when those columns exist).

Primary pillar equations (each output ∈ [0, 1])
-----------------------------------------------
Inner weights are fixed for transparency.

**Water_Risk_Score**
```
WR = 0.34·norm(Water_Stress_Index)
   + 0.28·norm(Drought_Risk)
   + 0.22·norm(Water_Price)
   + 0.11·(1 − norm(avg_Annual_Precipitation))
   + 0.05·norm(std(Rain_Jan…Dec))
```

**Climate_Load_Index** (thermal / HVAC load proxy; dashboard “Climate” pillar)
```
CL = 0.34·norm(Avg_Summer_Temp)
   + 0.30·norm(Cooling_Degree_Days)
   + 0.18·norm(Avg_Annual_Temp)
   + 0.18·norm(Heating_Degree_Days)
```

**Carbon_Impact_Score** (average of available normalized drivers)
```
Let S = { norm(Grid_Carbon_Intensity) }
If CO2_million_metric_tons merged: add norm(CO2_million_metric_tons)
If Grid_MWh merged: add norm(Grid_MWh)
Carbon_Impact_Score = mean(S)
```

**Energy_Cost_Score**
```
If Industrial_Total_USD merged:
  EC = 0.5·norm(Electricity_Price) + 0.5·norm(Industrial_Total_USD)
Else:
  EC = norm(Electricity_Price)
```

Total Impact Score (0–10)
-------------------------
User-adjustable weights (dashboard sliders): `w_water`, `w_climate`,
`w_carbon`, `w_cost` (non-negative; at least one positive).

```
Total_Impact_Score = 10 × (
    w_water·WR + w_climate·CL + w_carbon·Carbon + w_cost·EC
) / (w_water + w_climate + w_carbon + w_cost)
```

Default weights (balanced)
--------------------------
- w_water = 2.0  
- w_climate = 1.0  
- w_carbon = 1.5  
- w_cost = 2.0  

Example scenarios (see `site_scores.SCENARIO_WEIGHTS`)
-------------------------------------------------------
- **Balanced:** (2, 1, 1.5, 2)  
- **Carbon priority:** (1.5, 1, 3, 1)  
- **Cost priority:** (1, 2, 1, 3)  
- **Water priority:** (3, 1, 1, 1)  

Outputs for export / UI
-----------------------
- Water_Risk_Score  
- Climate_Load_Index  
- Carbon_Impact_Score  
- Energy_Cost_Score  
- Total_Impact_Score  

Assumptions
-----------
- Scores are **relative** to the cities in the current file, not absolute risk.
- Merged grid fields are **state-level** proxies for each city row.
- Currency-like strings are stripped to numbers before normalization.
